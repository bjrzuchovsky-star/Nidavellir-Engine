# 2D coin

A small 2D script in C# (`scripts/coin.cs`) and C++ (`scripts/coin.cpp`). The scene attaches the C# file. The coin's worth is a Prop and shows in the Inspector. Walking a rider into its trigger pockets it (toast, then it hides).

Swap the script path to `scripts/coin.cpp` to run the C++ twin. Neither script needs Rider.
