# Empty 2D Top-down

A top-down 2D claim: a Player with top-down movement (Player Controller, slot P1) and a collider, a follow camera (Camera2D) and an empty tilemap layer.

## Play

WASD / arrow keys / the left stick move the player on both axes. Solid tiles and static colliders block it.
