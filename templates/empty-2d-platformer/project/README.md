# Empty 2D Platformer

A side-on 2D claim: a Player with platformer movement (gravity 1400 px/s2, jump 560 px/s), two rows of solid ground tiles (Stone) and a follow camera.

## Play

A / D, the arrows or the left stick walk; W / Up / Space (action) jump while standing on something solid.
