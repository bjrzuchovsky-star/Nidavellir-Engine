# Empty 2D

A 2D claim with a camera (Camera2D), one empty tilemap layer (TileMap, 32 x 18 tiles of 32 px) and the 2D lighting off. Nothing else.

## Play

There is no player yet, so Play shows the camera's view of the empty map.

## Next steps

- Paint tiles on the TileMap (Tiles panel) or set a tileset image.
- Add an entity with a Player Controller and point the Camera2D's Follow at it.
- Turn lighting on in Scene settings when you want lights and day / night.
- No optional plugins are on. Turn them on from the Trading Post (or the Outfitter's Wagon) when you need them.
- Everything in this claim was made by the engine (CC0). Replace it freely.
