# Truly Blank (3D)

A 3D claim with no entities at all: an empty scene.json, an empty assets/ folder and this README.

## Play

Play runs an empty world (nothing moves until you add something).

## Next steps

- Create > Primitive, Light, Terrain or a glTF model to start.
- Add a Player component to ride something.
- No optional plugins are on. Turn them on from the Trading Post (or the Outfitter's Wagon) when you need them.
- Everything in this claim was made by the engine (CC0). Replace it freely.
